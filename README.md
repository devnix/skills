# skills

Agent skills for [Claude Code](https://claude.com/claude-code) and compatible agents, organized by category.

## Catalog

| Skill | Category | Description |
|-------|----------|-------------|
| [todo](productivity/todo) | productivity | Personal tracker for open tasks and concerns (a mixed drawer for dev/system/life). One Markdown note per task in an Obsidian-friendly vault, with metadata frontmatter and an update log. |

## Install

Copy the skill folder into your personal skills directory:

```sh
git clone https://github.com/devnix/skills
cp -r skills/productivity/todo ~/.claude/skills/todo
```

Then invoke it with `/todo` — or just talk: the skills trigger on natural language, in whatever language you speak to your agent.
